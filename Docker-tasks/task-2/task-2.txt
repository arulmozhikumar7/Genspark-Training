Pull the image : 
docker pull mysql:latest

Run the image in a container:
docker run -d \
  --name task-2-container \
  -e MYSQL_ROOT_PASSWORD=root \
  -v task-2-volume:/var/lib/mysql \
  -p 3306:3306 \
  mysql:latest

Access the client:
docker exec -it task-2-container mysql -uroot -proot
